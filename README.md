# Homebrew Tap

Personal Homebrew tap for custom builds.

## Installation

```bash
brew tap faisalmirza/tap
```

## Available Casks

### MarkText

Custom build of MarkText markdown editor.

```bash
brew install --cask faisalmirza/tap/marktext
```

To update:

```bash
brew upgrade --cask faisalmirza/tap/marktext
```
